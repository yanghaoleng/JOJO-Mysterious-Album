# 拯救宇宙的好奇心

三章共享一个任务：让朋友愿意继续提问、听不同的理由，再把想法做出来。章节线索只在本机保存；无需先通关，三个入口都能直接玩。

- 第一章：通过走路、观察、点选和短语音熟悉操作，用提问为宇宙找回颜色。结尾邀请孩子去听不同的办法。
- 第二章：先选三个救援问题之一，听两位伙伴用四句相互承接的对话商量，再说出自己的办法。孩子的这句话进入第三章开场。三个预置问题各有四句精写离线对话。
- 第三章：观星营地起步 → 为海底朋友造探索工具 → 组合口袋材料 → 给安静的问题造一个空间 → 共建月球广场 → 继续自由创造。每次创作后，由孩子选择继续修改或前往下一站。

## 造物和反馈

孩子可以说颜色、组合物品、点名角色，或说“给刚才的作品加……”继续修改。每件最多组合三种模型，每颗星球保留十二件；达到上限邀请修改，不会静默删除。背包可回访对应星球。已出现的朋友会到新作品旁，同一星球只出现一个可见实例。

- 彩虹小桥：桥板一块块亮起来，伙伴可以在桥边碰头。
- 问题花园：花瓣展开了，藏在花心的小星星跟着探出头。
- 发现果树：树枝轻轻摇起来，枝头的星星果一颗颗亮了。
- 好奇小屋：屋门打开了，窗里亮着一盏等朋友来的灯。
- 星光望远镜：镜筒转起来，旁边的星星按顺序亮了。
- 问题小机器人：机器人挥挥手，胸前的问号灯亮了。
- 探问小船：船桨划起来，船边浮出一串小气泡。
- 好奇火箭：推进器亮起来，火箭在底座上轻轻升起。
- 想象传送门：门里的光圈转起来，两边的星星互相眨眼。
- 云朵气球：气球牵起小篮子，慢慢升到绳子顶端。
- 提问风车：风车转起来，把星光送给旁边的小灯。
- 气泡喷泉：三束气泡轮流跳起来，落回自己的小水池。
- 星星音乐台：彩色琴键轮流跳动，星星音符也跟着跳起来。
- 分享点心台：蒸笼打开了，热气托起一只圆圆的星星包。
- 云朵秋千：秋千轻轻摇起来，吊绳旁的铃铛跟着摆动。
- 好奇灯塔：灯罩慢慢升起，灯塔周围的小光点跳起来。
- 小小表演台：帷幕拉开，聚光灯亮在你留给朋友的位置。
- 折叠探索梯：梯级从下到上轻轻抬起，顶端的小旗也摇起来。
- 发现照相机：镜头闪了一下，一张星星图案的相片升出来。

另有彩色积木试作品：无法匹配现有模型的想法会明确呈现为试作品，保留原话并邀请补充可见零件，不宣称实现了任意功能。采用本地模型组合与既有语音识别，不是运行时任意网格生成。作品、位置、原话只保存在当前浏览器。

## 验证

`node dev/tools/verify-curiosity-worlds.mjs` 检查 46 个角色点位、模型动作、20 种模型、组合与人名识别、所有彩蛋的可达路径和脚本结构。

`dev/tools/verify-curiosity-ui.mjs` 使用实际页面控件验证三章角色触发、对话与走动互斥、线索传递、六幕造物、修改和刷新恢复、背包回访、继续创造及 390px 页面。该脚本使用受控离线 API，不代表实机麦克风识别验收。
