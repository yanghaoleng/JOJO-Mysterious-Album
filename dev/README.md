# 萌萌星 · 立体故事工坊

独立实验入口：`https://jma.mikeywa.site/dev/`。没有替换旧版图鉴、旧故事、骨骼、资源或存档。

## 黄色四巨头

`yellow-four.html` 是独立的四人同框场景：黄牛、圆滚滚、叫叫、袋鼠，造型参考 2026-09-09 的两张图片。参考原图仅保留在本机 `output/yellow-four-20260909/references/`。新增三位角色只在这个合照场景出现；叫叫复用现有实体模型工厂。

支持拖动或方向键转动、滚轮和双指缩放、点角色打招呼、集体挥手和蹦跳、导出 2400 × 1600 PNG。使用本地网格和既有 Three.js，不依赖外部生成服务。构建：`node dev/tools/build-yellow-four.mjs`；与现有工坊预览服务共用。

## 人物优先的沉浸舞台

镜头按当前伙伴的实际轮廓构图，不按星球边界缩远；不同大小的星球可以自然延伸到画面外。场景标题和底部对话占用的区域会从人物安全区中扣除，展开回答方式、输入文字或改变屏幕尺寸时重新构图。拖动、缩放仍保留，故事菜单中可以「回到伙伴身边」。

`environments.js` 给 11 个场景分别定义 3.55～6 单位的真实半径，以及白天、黄昏、夜晚的浅色弥散背景与柔和补光；夜景不以压暗人物来表现时间。底部对话直接融入环境，默认只显示语音入口与「更多回答方式」；选项和文字输入按需展开，背包、场景复位、重新开始收进顶部故事菜单。开始故事只解锁播放，不自动申请麦克风。

## 新模型与场景

- `models.js`：原创圆润实体模型，独立眼睑、嘴、耳尾与配件；网格局部运动，不使用 Bone、SkinnedMesh、蒙皮权重或旧版动画资源。
- `assets/characters/`：7 份真实 Object3D 网格文件；曲面形变、法线和 UV 可无损重新读入。授权见 `assets/README.md`。
- `worlds.js` / `planet.js`：11 个完整小星球，包含果园、面包房、木桥、家门、观星台、海底、巨人口袋、云层、月面、萤火草地与河湾。景物和角色沿球面站立，侧面、背面与南半球也有对应主题地貌；保留行动反馈。
- `storybook.js`：实时手作绘本材质，低高光、柔和明暗色块，以及贴合模型表面的纸浆纤维、织物、木纹、石粒与水彩积色。材质通过 `handcraftedSurface` 明确区分纸、布、木、石、叶、水、彩绘和干净的五官；眼睛不套用粗糙纸纹。保留原材质颜色引用，不额外增加绘制通道。
- `stage.js` / `inventions.js`：可上下环绕、水平旋转的小星球，支持滚轮与双指缩放、回到正面；被球体挡住的角色不可隔球点选。导航屏、浮筒、推进器、绳索、梯子、桨和帆会逐次留在原发明上；明确要求换方案时才替换主体。
- 模拟器导出的是网格与材质，以及 `object.userData.recipe` 中的编辑参数。下载文件不包含独立动画运行时；动态行为由本目录源代码提供。
- 程序化质感不需要下载位图，也不会被 Three.js 序列化成图片。导出的标准材质保留 `handcraftedSurface` 分类和 `storybookStyle` 参数；外部通过 `ObjectLoader` 读入后，可调用 `createStorybookStyle().apply(object)` 恢复纸感与微表面凹凸。

材质方向参考 2015 年《小王子》中纸艺世界的手作语言。[官方制作资料](https://wwws.warnerbros.co.jp/littleprince/)介绍了纸、黏土、水彩与自然布光的结合。本项目保留原创角色、景物与动作，不复制电影模型、角色、截图或纹理；这里实现的是实时 3D 材质，不是影片中的实拍定格动画。

## 隔离与服务

所有产品代码在 `dev/`；仅只读复用项目原有的 Three.js、图标包和 favicon。没有改首页导航，没有注册 Service Worker。存档前缀为 `jma.dev.clay.v1`，不会读取、覆盖或清空旧版存档。

复用既有无状态 `/api/tts`、`/api/asr`、`/api/story-turn`、`/api/moon-director`。`story-api.js` 显式适配旧 HTTP 白名单，仍把新场景的完整问题、选项与剧情约束交给服务；不要求变更旧后端。月线最后的纪念选择保留在本机。

只有主动打开麦克风才申请权限。只在等待回答时采集；角色讲话时暂停，结束后留 350ms 声尾；暂停或离开页面会停止轨道并取消未完成识别。录音仅为当次识别临时放在内存；进度不存录音。界面提供点选与文字后备，不因没有麦克风阻断故事。不要输入真实姓名、学校、地址等个人信息。

## 构建与验证

在仓库根目录运行：

```sh
node dev/tools/build.mjs
node dev/tools/verify-assets.mjs
node dev/tools/verify-planet.mjs
node dev/tools/verify-storybook.mjs
node dev/tools/verify-api-contract.mjs
node dev/tools/verify-inventions.mjs
node dev/tools/verify-voice.mjs
```

本地预览：`node dev/tools/preview.mjs 8914`。默认不调用线上 API；确需验证真实语音时，显式设置 `DEV_API_BASE=https://jma.mikeywa.site`。此本地预览工具只监听回环地址，不作为生产服务。

`verify-story-flows.mjs`、`verify-studio-ui.mjs` 与 `verify-immersive-ui.mjs` 使用真实浏览器控件验证。沉浸脚本覆盖 11 世界、3 种视口、人物安全区与实际遮挡、菜单和键盘、回答方式展开，以及独立测试会话中旧版模拟存档的逐字节保留。可用 `DEV_QA_BASE` 指向预览或上线 URL，使用独立会话，不改真实用户业务状态。`verify-planet-ui.mjs` 和其旧报告保留为上一版「完整星球入镜」的历史证据，不再作为本版人物优先构图的验收条件。报告是指定版本、指定路径的检查证据，不等于覆盖所有自由表达或实际手机声学环境。

发布把本次修改的运行资源放入当前生产版本的副本，通过版本目录原子切换，并核对发布文件的校验值。这次另为共享实体角色模型增加只读跳跃高度接口；原后端与其他页面保留当前生产版本。旧发布目录保留，可回退。

## 好奇光的3D版与脚底接触

`wow-story.js` 适配同一份 `src/wow-story-data.js`，以独立 `jma.dev.clay.v1.story.wow` 保存记录；不会读写原版好奇光存档。`wow-visuals.js` 提供六种实体MOMO、星星窗、三道具、六种钥匙形状与随回应变化的光。复用 `/api/wow-turn` 的AI短回应与受限形状/颜色映射；断网时采用同一安全规则的本地回应，并标示来源。完成后可下载保留原话的HTML纪念册。

角色站立时按真实足底几何和球面曲率计算接触位置，随体型、摆动和迈步更新；显式跳跃高度单独保留。`verify-grounding.mjs` 检查56种角色、两种尺寸与2352个动作姿态，避免固定抬高造成的悬空。新增MOMO通过 `config.createActor({scale})` 接入舞台。

每章从夜色与迷雾开始。只有本章已经接纳的回答推进光照和能见度，重复、等待或取消不增加进度；收集本章颜色时进入清晨，下一章重回浓雾。八层柔边实体雾与场景深度雾共同遮挡中远景，MOMO面部仍可辨认。按保存进度恢复明暗，减少动态模式直接应用目标状态。`node dev/tools/verify-wow-atmosphere.mjs` 检查六章进度、光照、雾距离、恢复与隔离。
