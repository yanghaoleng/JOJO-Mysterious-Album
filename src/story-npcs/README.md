# 故事 NPC 角色库

本次依据 2026-09-06 收到的三张角色设定图和《叫叫-IP设定资料》制作。图和文档的私有原件不在仓库中；本目录只有独立制作的三维几何、经过整理的角色摘要和原创示例台词。文档转发日期不代表文档更新日期。

## 使用边界

- 42 个正式角色设定，全是 NPC，不进入用户创建伙伴的选择表。
- 叫叫、铃铛、猪小弟同时出现在原版与 Dev《送豆豆回家》的指定场景。其他 39 位先在两版共用的“故事里的朋友”角色库中提供模型和试听，不自动替代现有剧情人物。
- 原版面包房 / 木桥 / 两座房子分别由猪小弟 / 叫叫 / 铃铛承担当前主要对话。Dev 面包房 / 河边 / 两座房子对应相同三人。主角豆豆、妈妈、点点的船和水滴印章不变。
- `visualBasis` 区分三张 3D 参考、文档插图、文字演绎。无具体服装设定的形象是本次绘本适配，不宣称原始官方模型。真人演示图片只参考服装和发型，不复制演员面容或克隆其声音。
- 使用现有 15 种合成音色预设；42 个角色不是 42 个独立音色模型。每位设置独立说话风格及 0.86–1.08 的语速。浏览器无网络时的设备朗读不能保证相同音色。

## 接口

`catalog.json` 为唯一资料源。修改后运行 `node src/story-npcs/generate-catalog.mjs` 生成不依赖 JSON import attributes 的 Safari 兼容 `catalog.js`。

`factory.js` 导出 `createDocumentCharacter({ characterId, scale })` 和 `supportsDocumentCharacter(id)`。42 个模型脚底为 0、标准站高为 2.2、面向 +Z，支持 idle / talk / wave / hop / listen / walk 与四种表情。场景移除模型后调用 `dispose()`；绘本材质由 `dev/storybook.js` 在使用侧施加。

后端只接受受控的 `npcId`，从本地角色库取人设和音色，不接受客户端自报角色性格。原版与 Dev 的 NPC 发言向对话和 TTS 服务传递同一个 ID；用户伙伴发言不携带 NPC ID。儿童安全和场景选项白名单始终优先于角色口吻。

## 验证

- `node src/story-npcs/generate-catalog.mjs --check`
- `node src/story-npcs/verify.mjs`：42 profile、126 模型尺寸、3024 组动作表情、18 幕关联、旧伙伴存档、TTS 身份和 48 次角色切换的离线回归。
- `node dev/tools/verify-assets.mjs`：原 7 种伙伴、11 个世界和已有故事资产合约。
- `node dev/tools/build.mjs`：重建 Dev，所有模块使用同一个 Three.js 实例。

浏览器验证另行进行：真实 DOM 完整走通 Dev《送豆豆回家》，保留刷新续玩和背包保存；390px 检查三位 NPC 无横向溢出且在安全取景范围。角色库逐位目视检查。离线模型/接口测试不证明真实麦克风、听觉音色体验或所有自由回答的质量。

原版的手机视觉检查使用现有诊断入口载入合成场景，不使用真实麦克风：逐一验证三位模型、口型、气泡边界、切回旧角色和用户伙伴不变。同时修正通用气泡样式覆盖原版锚点变换造成的右侧裁切。
