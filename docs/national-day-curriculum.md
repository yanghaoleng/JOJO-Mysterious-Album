# 我的国庆大冒险 · 词汇与96题课程

独立入口：`/national`。12站，每站8题，逐题继续；当前进度自动保存在本机。

前48题可以逐词搭建；49至80题练完整表达；最后16题可用自己的词组合，最后8题引导连续两句话。每站开启新布景，不要求一次玩完。

主题词包括国旗、星星、气球、灯笼、长城、山、熊猫、地图、行李箱、交通工具和家庭野餐。92个去重英文词形包含复数与句式支持词，并非92个独立名词。

## 教学参考

参考下列假期与交通主题确定生活化选词范围。题目、中文提示和96题顺序为本项目原创；不冒称全部来自R线原词库，也不复制外站练习。
