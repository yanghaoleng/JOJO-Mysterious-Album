# 哇呜！第一束好奇光

## 创作依据与定位

本故事依据钉钉文档《【策划初稿】MMX的奇妙图鉴 -20260901》创作。原文节点：`oP0MALyR8k7rLQ4MiDkwygEw83bzYmDO`，读取原文留档为 `/tmp/mengmeng-creative-source.json`。正文保留原案的世界、MOMO、六色与能力，对人物关系、跨章因果及第一章教学节奏重新编排。

**一句话：**孩子的一句话点亮一盏小灯；跟着这句话的回声，孩子穿过六个世界，发现自己的感受、问题与想象都值得被听见。

**对孩子说：**你问一句，星球亮一格。

**故事的承诺：**任何认真表达、暂时不确定、选择安静、通过示范句表达，都可以被接住。没有标准答案、答错扣分、倒计时、坏人或“只有你能救它”的责任。MOMO有自己的选择和行动，孩子是同行的朋友。颜色一旦留下，休息不会使它消失。

## 一条连续的因果线

孩子推开星星窗，听到无人解释的咚咚声。开口后，小灯真的亮起。光照出鼓鼓，也照出听不清彼此的困难；唔姆收音机让问候与回信来往。孩子先观察、倾听、提问，再把一个想法变成钥匙，进入点心花园。鼓鼓说清自己的感受，做出照顾自己的选择，第一滴黄色才出现。

暖黄光照到海螺，海螺带来灰灰的声音。孩子在海底找到被杂物盖住的贝壳，让回收小车经过门，把声音还给一条小路。贝壳歌声传到水面，水光把视线引向发抖的憋憋。孩子陪它寻找舒服的表达空间，憋憋自己落下一滴雨。雨碰响风铃，露出把早晚混在一起的乱乱。乱乱决定先休息，小屋的灯照见总藏起来的躲躲。孩子让一条路允许弯曲，躲躲自主走出一小步；顺着这条路，它发现一直陪着自己的那一点星光。

点点觉得自己不够亮，却想给晚归的人留灯。孩子陪它把这个愿望变成当下能做的小事。最后一把钥匙打开回声花园，六种颜色各自亮起，MOMO们说出孩子最初的那句话。第一束好奇光不只是“让世界变漂亮”，也是孩子的声音被认真保存、被另一端回应。

### 第一章不可破坏的顺序

异常与轻请求 → 孩子第一句表达 → 手电筒响应并命名 → 世界与雾命名 → 遇到MOMO → 交流困难引出收音机 → 鼓鼓说自己的感受 → 孩子提问 → 空白门引出钥匙造物 → 看见门打开和情绪回应 → 颜色出现 → 颜色罐首次授予 → 轻轻指向下一章。

开场禁止同时摆出三个道具说明或六关任务清单。落地页可以让家长预览六个世界，进入第一章后应按上述认知顺序逐项出现。

## 数据契约与体验要求

故事数据导出 `WOW_STORY`，含 `title`、`subtitle`、`chapters`。每章具备 `id/title/world/momo/color/colorName/ability/summary/scenes`。每幕含 `id/speaker/text/prompt/kind/suggestions`，按需含 `prop/reward/placeholder`。

- 六章幕数为 **10 / 6 / 6 / 6 / 6 / 7**，共 **41幕**，所有章节有完整可推进脚本。
- `kind` 仅使用 `observe/light/listen/question/create/color/finale`。
- 第一章 `prop` 只在第2、4、9幕给出，分别是 `torch/radio/jar`；其余章节复用已有物品。
- 每章恰好一幕 `create`，恰好一幕 `color`，每章完成色通过该幕的 `reward` 记录。
- 每幕两条 `suggestions`，作为同等有效的示范表达，不存在题库式正确答案。
- `observe` 允许轻点继续或采用示范，但仍呈现邀请性提示；其他幕接受一句自由回应或示范回应后推进。
- 标准角色对白控制在80个汉字左右。终章包含 `{firstWords}` 的文本需先替换后进入语音：较长首句应分段朗读，不能因单次TTS限制让整章出错。
- 首句应当取本次真实提交的第一句自由输入或实际点选的示范，不能预先代填后宣称来自孩子。修改/重开旅程时同步刷新该值。
- `color` 幕应在完成交互时获得该色，避免提前进入章节即宣称已完成。
- 输入收录与造物需要在本机保存后才显示“已保存”；清除本机记录必须有明确入口和解释。

## 当前实现与规划的措辞边界

这条路线交付的是六章可体验故事、逐步出现的道具、可见且响应描述的程序绘制钥匙、六色收藏、首句回响与本机旅程纪念册/下载。实际界面由体验引擎负责，数据脚本不自行调用语音或远端服务。

落地页可以说“说一句，造出你的钥匙”“六个世界，六次被听见”“把这一路的话收进旅程纪念册”。如果语音识别受浏览器限制，应同样突出“说出来，也可以写下来或点一句”。

原文的AI全书创作、个性化MOMO生成、自动分类为什么树、成长分析、AI绘本插图都属于后续能力规划。没有实际接入、结果可查看和失败处理之前，不得宣传为本版现成功能。纪念册属于记录与程序拼版产出，不是AI创作证据；互动台词为这份脚本的编排，不宣称角色能自由理解任意语义。
